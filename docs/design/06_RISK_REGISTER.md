## Standing mitigations (cross-risk)

1. **The slice is sequenced to de-risk in order:** day loop + save (R-10) → utilities readable (R-08) → **construction core: bays, works orders, one reclaim arc (R-21)** → survivors (R-09) → radio → delegated runs (R-06 hedge) → active runs last (R-01 descope ladder).
2. **Every stage gate re-scores this register**; any risk at High/High blocks stage advance until mitigated or descoped.
3. **Provenance log** (asset source-of-truth record) starts with the first asset, serving R-03 and R-13.
4. **Playtest cadence:** readability tests (can a player explain a failure's cause?) begin at blockout, not at polish.
